# FLOAT NOTES（フロート・ノーツ）

SIKUMI NOTES 03。荷物を積んだ船の沈む深さを計算で予想し、水・油・水銀の違いを確かめる航海パズルです。

## 動かし方

```text
npm run dev       # 開発用サーバー
npm test          # 自動テスト
npm run check     # 構文の確認
npm run build     # dist/ に配信用の資材を作る
npm run build:artifact  # 確認用の1ページを作る
```
