# 荷物の比重と見本の大きさ

要件定義書5章の設定値を使っています。数値や計算の変更は行っていません。

同じ重さなら、体積は「重さ÷比重」で決まります。木の体積を1とすると、数値上の体積比は次の通りです。

| 素材 | 比重 | 同じ重さでの体積比（木=1） |
|---|---:|---:|
| 木箱 | 0.5 | 1 |
| 木の板 | 0.5 | 1 |
| 麦袋 | 0.7 | 5/7 |
| 中空の壺 | 1 | 1/2 |
| 石 | 2.5 | 1/5 |
| 鉄 | 8 | 1/16 |
| 鉛 | 11 | 1/22 |
| 金 | 19 | 1/38 |

これはゲームの設定値による体積比です。個々の絵の塗り面積を体積として測るものではありません。木箱と板では形が違い、丸みや縁取りにも見かけの差があります。

## 今回確認したこと

- 荷物8枚は全て1254×1254の透過PNGです。
- 木箱と木の板は金より大きく描かれ、金が8枚の中で最小になっています。
- [比較見本](17-cargo-equal-mass-comparison.png)は同じ重さでの大小関係を伝える絵です。
- 単体素材には比較用の透明な余白があります。余白を切って全素材を同じ幅へそろえると、絵で示した大小の関係が変わります。

## 組み込み時の扱い

実際の荷物の幅・高さは、要件書の「大きさ=重さ÷比重」「1マスを体積4として形に丸める」に従います。絵のピクセル数を計算や判定に使わず、荷物の配置や形に応じて画面側で表示します。今回の作業では、そのコードは変更していません。
