## 描画の引き継ぎ

紙芝居は `public/graphics/chapter-melody.webp` と `chapter-melody-chart.webp`。原本2枚は1448×1086px、配信用は960×720pxです。1枚目をs11、2枚目をs12で使います。既存の語り・セリフは保持しました。

船の関門・岸壁・札は `src/ui/melody-art.js` のSVGです。寸法は呼び出し側の値を使い、木目や紙目は固定寸法の模様を繰り返します。橋の下面と浅瀬の上面は従来の計算基準を使います。港番号・荷の山の段数は画面側の文字です。

橋の高い荷の停止位置だけは、発案者が「荷に接する位置へ直す」を追加承認しました。`bridgeContact()` は危険な荷の最前端を求める表示用関数で、衝突判定・音・進む順番・各動作時間は変更していません。船べり自体が当たる場合は従来の船首先端を使います。

横置きでは左を航海図・数値・説明、右を船・荷の棚・操作に分けました。844×390の1列の幅は13.73→27.65px。縦画面は従来の順番と寸法です。実機の指操作・聴感は未確認です。
