## 描画の引き継ぎ

`src/ui/classic-art.js` に船台、水中レバー、入れ替え室、航路図の液体・レバー・入れ替え室・港の旗・緑の帯を置いた。砂・木・石・金属の模様は固定寸法で繰り返す。数値は `classic.js` 側から渡し、文字も画面側で描く。

船の `bottomY()`、船べりの基準、関門の高さ、停止位置、入力と進行は保持している。船台の支えは船底に合わせ、レバーの接触面は判定の高さへ合わせる。レバーを押す10pxの動きも元の処理を使う。

棚は8個の荷を2列へ分け、選んだ荷は色と✓で示す。名前・重さ・押す場所を広げ、縦横やPCでも一画面内に収めた。案内欄の固定高さは保持し、操作段も文字の違いで高さが変わらないようにした。
