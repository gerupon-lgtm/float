実際のアプリの確認画像であり、画面へ表示する素材とは分けている。新しいラスター画像は作成していない。

画面は `src/ui/guide.js` と `style.css`、説明の図は `src/ui/guide-art.js`。採用済みの船・荷・水面・レバーの画像と、可変寸法の橋・浅瀬・紙札のSVGを再利用した。♪、港の札、荷札は本体と同じ輪郭・寸法・色で描く。

比重・底面積・船の高さなどは `src/logic` から取得する。計算図は既存説明の「船全体の重さ35」の例を同じ計算に渡している。数字は画面の文字であり、画像には描き込んでいない。

目次から項目を開く。スマホ縦では目次を開閉し、横置き・PCでは目次を左へ置く。本文と目次は必要に応じてそれぞれスクロールし、上の「表紙へ」は常に操作できる。

水銀の注意は、液体の項目を閉じたときは外側の注意枠に、開いたときは本文の強調枠に出る。元の文章と数値・条件は保持した。スマホの物理端末での読みやすさ・指操作は未確認。
