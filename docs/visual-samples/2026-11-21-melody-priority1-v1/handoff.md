## 描画に使うデータ

- 航海図のお題：既存の `ROUTE.target` を使う。0.5刻みの深さ・音名は本体の `midiOf` と試作の `NOTE` のまま。
- 関門：`ROUTE.cond[i]` の `k` と `d`。浅瀬は深い側、橋は浅い側をふさぐ。橋の段数は既存の `rowsUnderBridge` のまま。
- 港：`ROUTE.ports` の `k === 'down'` は↑、積む港は↓と `item[1]`（名前）・`item[0]`（重さ）。
- 実際の線と合否：既存の `S.played[i].d / ok / name` を表示する。ここで再判定しない。
- 小さな船：現在海路 `S.seg` と既存の深さ。船の下端をその深さの線へ合わせる。
- 荷札：既存の積載順 `n+1` と荷 `item[0]`。個々の重さは伏せない。
- 看板：`S.sign` と準備中の既存条件で文字を重ねる。板PNGには文字は入っていない。
- 手がかり：元の `showLive / showWeight / shownDepth` を維持。伏せている間に船の沈み方から答えが漏れないようにする。

## 移植の境界

見本は、既存の試作を別ページへコピーして外観だけを変えたもの。コピー中の出航・音・合否等を別の正典として増やさない。本体への組み込みではClaudeが流れを担当し、合意した描画・CSS・板素材を必要な場所へ移す。

`src/`、元の `proto/melody/`、`package.json` は今回変更していない。本体は0.8.24のままで、見本には独立した0.1.4を表示する。mainや本番サイトへは公開しない。

荷の選択肢の背景全体は、一枚の木の板。キャラクターは置かない。0.1.4では選択肢と枠の重なりを直すため、専用の平らな板 `cargo-board-v2.png` を使う。`.shelf-board` は `aria-hidden`・`pointer-events:none` の装飾で、荷の操作や読み上げには含めない。

棚の内側は上下12px・左右10pxの余白を取る。文字の表示幅を維持するため、棚の荷の絵だけ27pxから23px幅へ変更した。船側の絵と荷札の寸法は保持している。移植時は、5個の選択肢がある状態で外縁との間隔を確認する。

数字の太さは両ブラウザで確認する。今回はSafari系で重さの数字が細く見えたため、カード・棚・荷札の重さをArialの太字にそろえた。日本語の本文と語りの書体は本体から引き継ぐ。
