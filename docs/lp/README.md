## 使用技術と役割

| 技術要素 | このアプリでの役割 |
|---|---|
| HTML / CSS / JavaScript（ES Modules） | 画面・操作・計算・音を構成。追加のライブラリは使わない |
| SVG＋画像（WebP） | 航路の盤面に、船・荷物・液体・関門の絵を重ねる |
| 分数計算（BigInt） | 沈む深さの判定に誤差が混ざらないようにする |
| 問題の自動生成と検査 | 面ごとに問題を作り、解けることや、理由なしに解けないことを確かめる |
| Web Audio API | 音をその場で合成する。畳み込み残響で短い響きを付ける |
| FM合成 | 沈む深さを音の高さとして鳴らす。深いほど低い |
| PSGノイズ | SCCシミュレーターの部品で、荷物の着地、拍子木、沈没の打楽器音を作る |
| localStorage | 連続プレイの記録と、見た紙芝居を端末に保存する |
| PWA：Service Worker / Cache Storage / Web App Manifest | 準備後は通信なしでも遊べる |
| GitHub Actions / GitHub Pages | テストとビルドのあと、独自ドメインへ公開する |
