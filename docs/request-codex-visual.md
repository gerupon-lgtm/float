# Codex への依頼：FLOAT NOTES のキャラクターとUI

2026-11-05 Claude 作成。発案者の依頼により作成しました。発案者が、この依頼書をもとに Codex へ依頼します。

## 1. 作品の概要

FLOAT NOTES は SIKUMI NOTES の03作目です。船に荷物を積み、水・油・水銀での沈む深さを計算で予想するパズルです。

見習いの少年がアルキメデスのもとで、「分かったつもり → えっ？ → やって確かめる → エウレカ！」を繰り返す物語です。

前2作の夜空や陶器の透明感とは変え、**クレヨンの手描きと紙の質感の紙芝居**にします。前2作の精霊は使いません。

## 5. 守ってほしいこと

- **読み取り：** 沈む深さと、液体の違いが一目で分かること。色だけに頼らず、形や文字でも分かること。消音でも結果が分かること。
- **スマホ優先：** 縦画面を基本に、PCでも使えること。確認端末は Pixel 6a と iPhone XR です。
- **文字：** 絵の中に、説明文を焼き付けないこと。文言は画面側で変えられるようにします。
- **荷物の大きさ：** 同じ重さなら、木は大きく、金は小さく見えること。比重と大きさの設定は要件定義書5章に従います。
- **風呂の場面：** 裸を描かず、札や湯気で隠して、年齢を問わず見られる表現にすること。
- **水銀：** 架空の湖として描き、安全で楽しい液体に見せないこと。注意書きが読めること。
- **史実：** 王冠の話は伝承、見習いは創作です。歴史の資料のように見せないこと。
- **独自性：** 既存の作品のキャラクターや場面に似せないこと。
- **容量：** 配信する絵は軽くすること。候補の原本は、リポジトリに入れなくてかまいません。
- **計算：** 計算と判定を変えないこと（C-01）。配置や文言は、発案者の指示で変えてかまいません（0章のA）。
