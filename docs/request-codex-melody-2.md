# Codex への依頼（2回目）：航路のメロディの導入の紙芝居と、仕上げ

2026-11-21 Claude 作成。発案者の依頼により作成しました。発案者が、この依頼書をもとに Codex へ依頼します。

## 1. いまの状態

航路のメロディは、本体に5面（メロディ0〜4）として組み込み、公開しました（v0.9.15）。前回の見本0.1.4の絵と配置を移したうえで、発案者と試しながら、次のものを Claude が仮の絵で足しています。

| 足したもの | 場所 | いまの描き方 |
|---|---|---|
| 積む操作の影 | 船の上 | 荷を選ぶと積める範囲が光り、押している間は落ちる位置に点線の影が出る |
| 荷の山の段数 | 看板の右 | 白い札に「荷の山 ○段」 |
| 関門の通り抜け | 出航後の船の右 | 浅瀬の砂、橋（柱2本と橋桁）を右から左へ流す。当たると船首の前で止まり「ゴツン！」 |
| 港の岸壁 | 寄港中の船の右 | 石積みの岸壁、杭、赤い札「港○」。最後の港は終着で、そこに泊まったまま最後の音を鳴らす |
| 航海図の音符と港番号 | 航海図 | お題は♪、港は赤い札「港1」…、最後の港に「終着」 |
| 導入の紙芝居 | メロディ0の前 | 文だけ入れた。絵は港の絵（harbor）を仮に使っている |

関門と岸壁は、Claude が SVG で描いた仮の絵です。

## 4. お願いしたいもの

### 優先度1：導入の紙芝居の絵

連続プレイでも選択プレイでも、この面（メロディ0）に初めて入るときに、紙芝居が2枚流れます。2回目からは飛ばし、表紙の「おはなし」の「航路のメロディ」で読み返せます。

| 場面 | 文（変えてよい） | 絵の内容の案 |
|---|---|---|
| s11 | 語り「王の荷を届けた帰り道。港に寄るたびに荷を下ろすと、船は少しずつ浮いていきます。」／見習い「あれ？ 浮くたびに、船の鳴る音が高くなっていく……！」 | 港で荷を下ろす船。見習いが耳を澄ませて驚く |
| s12 | 語り「アルキメデスは航海図を広げ、港と港の間に音符を書き込みました。」／アルキメデス「重さが深さを決め、深さが音を決める。ならば、荷の積み方で歌も作れるはずだ。港の間の音を、この♪に合わせてごらん。」 | 航海図（港の印と音符）を広げる師匠と、のぞき込む見習い |

- 1枚の絵を2場面で使ってもかまいません。
- 保存先は `public/graphics/chapter-melody.webp` です。この名前で置き、`src/ui/graphics.js` の `GRAPHICS` に `'chapter-melody'` を足すと、仮の港の絵から自動で切り替わります。
- 2枚に分ける場合は、`src/ui/art.js` に絵の名前を足し、`story.js` の `art` を書き換えてください。
- 文字は絵に描き込まないでください（前回と同じ）。

### 優先度2：仮の絵の差し替え

Claude が SVG で描いた仮の絵を、作品の絵柄にそろえてください。

| 名前 | 内容 | 守ること |
|---|---|---|
| 橋（船の画面） | 柱2本と橋桁 | 橋桁の下面の高さは、判定と同じ基準。位置と高さは `shipSvg` の計算に従う |
| 浅瀬（船の画面） | 斜面のある砂の海底 | 海底の上の面の高さは、判定と同じ基準 |
| 岸壁 | 石積みの岸壁、杭、港の札の板 | 札の文字（港○）は画面側で入れる |
| 荷の山の札 | 「荷の山 ○段」の札 | 文字は画面側で入れる |

絵は、高さや幅を変えて当てても崩れない形にしてください（関門の高さは、お題ごとに変わります）。

### 優先度3：横置きとPCの配置

前回の優先度3です。いまは Claude が仮に、左に航海図、右に船と操作を並べています。844×390 では船の絵が小さく、積む範囲を押しにくいので、そこを中心に見直してください。

## 5. 守ってほしいこと

- **計算・判定・お題・進行を変えないこと（C-01、C-03）：** 船が動く順番と時間、関門で止まる位置は、Claude の担当です。絵を差し替えるときは、位置と高さを `shipSvg` の値に合わせてください。
- **見た目の高さを判定に合わせること：**
  - 船の絵の船べりは、船の高さ5に合わせています（`BOAT_TOP`）。
  - 橋の下面と浅瀬の面も、判定の高さで描いています。
  - 絵が判定とずれると、当たっていないのに当たって見えるので注意してください。
- **音なしでも遊べること、スマホ縦の1画面に収めること：** 前回と同じです。
- **配置や文言の変更：** 発案者の指示で、すぐに変えてかまいません（0章のA）。
