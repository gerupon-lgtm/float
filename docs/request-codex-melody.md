# Codex への依頼：航路のメロディ（F-020）の画面と絵

2026-11-21 Claude 作成。発案者の依頼により作成しました。発案者が、この依頼書をもとに Codex へ依頼します。

## 1. 何を作るか

FLOAT NOTES に、新しい種類の面「航路のメロディ」を加えます。

船は港を順に回ります。港で荷を下ろすと船は浮き、荷を積むと沈みます。海路ごとの沈む深さが音になり、航路全体がメロディになります。遊ぶ人は、お題のメロディと同じになるように、出航前に荷を選んで積む順を考えます。

遊び方は、動く試作で発案者が確認済みです。今回お願いしたいのは、この面を本番の見た目に仕上げるための、絵と画面の配置と演出です。

## 4. お願いしたいもの

大きさや形は目安です。使いやすい形に変えてかまいません。

### 優先度1：画面の案と絵

| 名前 | 内容 |
|---|---|
| 航海図（深さの図） | 横は海路の順番、縦は深さです。上ほど浅く、音は高くなります。各海路のお題の点、目盛りの深さと音名（ド〜ド）、港の印を描きます。港の印は、下ろす港が「↑」、積む港が「↓」と荷の名前・重さです |
| 浅瀬と橋 | 航海図の同じ目盛りの上に描きます。浅瀬は、その深さより下の海底です。橋は、その深さより上をふさぐ橋桁と、「荷は何段まで」の表示です。海路の幅は細長いので、引き伸ばしても崩れない描き方が必要です |
| 航海中の船 | 航海図の上を、今の深さの高さで進む小さな船 |
| 合否の線 | 通しで聴くとき、実際に通った深さをお題の点に重ねます。合っている海路と違う海路を、色と記号（×と音名など）の両方で見分けられるようにします |
| 看板 | 「積載中」（出航前と、港で積むとき）と「荷下ろし中」（港で下ろすとき）。文字は画面側で入れるので、絵は板だけにしてください |
| 荷札と重さ | 積んだ荷に付ける、積んだ順の番号の札と、重さの数字。一番小さい荷は1マスなので、そこでも読める大きさにします |
| 1画面の配置 | スマホ縦の1画面に、次のすべてを収める案です。航海図、重さ・深さ・音のカード、船と積む場所、荷の棚、語り、ボタン（お題を聴く・ひとつ戻す・出航） |

作業量を確かめたいので、最初はここで止めて、発案者の確認を受けてください。

### 優先度2：演出

| 名前 | 内容 |
|---|---|
| 港で積む | 荷が上から落ちてきて、着いた勢いで船が沈む。「積んでいる感」を出す |
| 港で下ろす | 荷が持ち上がって消え、船が浮く |
| 通しで聴く | 最後の荷下ろしの後、航海図の上を船が進み、海路ごとに音が変わる。最後にエウレカで「ド」に帰着する |
| 練習面の案内 | 組み立ての進み具合に合わせて変わる案内の見せ方。紙芝居の語りと同じ雰囲気にする |
| 導入の紙芝居 | この種類の面に初めて入るときの紙芝居（1〜2枚）。作るかどうかは発案者が決めます |

### 優先度3：横置きとPC

本体の他の面と同じく、横置き（幅が高さより大きい画面）とPCの配置を作ります。

## 5. 守ってほしいこと

- **音なしでも遊べること：** お題は、航海図の点の高さで必ず読めるようにします。合否も、色だけでなく形や文字で分かるようにします。
- **航海図の情報量は、難しさで変えないこと：** 難しさは、組み立て中に出す手がかりで変えます。
  - フリー：重さ・深さ・音を出す
  - ノーマル：重さだけを出す
  - エキスパート：何も出さない
  - 手がかりを伏せている間は、船も空荷の深さで描きます（沈み具合で答えが分からないように）。
- **荷の重さは常に見せること：** 合計を伏せるレベルでも、自分で足し算できるようにするためです。
- **スマホ縦の1画面に収めること：** 確認端末は Pixel 6a と iPhone XR です。
- **文字を絵に焼き込まないこと：** 文言は画面側で変えられるようにします。
- **計算・判定・お題を変えないこと（C-01、C-03）：** 次のことは、Claude の担当として変えないでください。
  - 深さと音の対応
  - 荷を下ろす順（最後に積んだ荷から）
  - 港で積む荷の置き場所（空いている中で一番低い位置、同じ高さなら左）
- **試作専用の部品は、本番に入れないこと：** 次の3つは、試作で比べるためだけに置いたものです。
  - 「フリー」の選択欄
  - 帰着のド「下／上」
  - 「自由／練習／お題1」の切り替え
  - 「音あり／音なし」だけは、本番にも残します。
- **配置や文言の変更：** 発案者の指示で、すぐに変えてかまいません（0章のA）。

## 7. 未決のこと

- **帰着の「ド」：** 上のドか下のドかは、実機で聴いて決めます。
- **面の数：** 機械で多数作れるので、発案者が聴いて選びます。
- **船に積める荷の数の上限（Q-10）：** 試作で確かめてから決めます。
- **油など、ほかの液体を使う時期（Q-17）：** まず水で成り立たせてから決めます。
