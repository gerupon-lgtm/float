# 元の遊び方の絵と配置の仕上げ（v0.9.26）

2026-11-22。依頼：`docs/request-codex-classic.md`。基準はmainの `57b50120ff15042fe5c7abb4135e82a66e7cfe13`（v0.9.24）。依頼書にあるclassic-layoutの変更はすでにmainへ公開されていたため、この版から作業した。

## 絵と配置

船台は砂の斜面と木組みの支え、水中レバーは金属の柱と赤い押す面に整えた。船台の支えの高さは船底122に一致し、船の位置は変更していない。レバーの接触面は `WATER + 深さ×U` の高さで切りそろえ、押したときの動きは既存の10px・300msを使う。

入れ替え室では、看板と液体の色の変化に加えて枠・管・弁を描く。既存の「入れ替え室」の表示中だけ描き、切替前後の待ち時間と浮き沈みは保持する。航路図にも液体が左右で変わる枠を添える。

航路図の液体・緑の帯・港旗にクレヨンの模様を加えた。帯の範囲、液体が切り替わる列の中央、深さの目盛り、橋・浅瀬・レバーの数値と位置は保持する。水1〜3だけに帯が出る決定も保持する。

水銀1・2の8個の荷は2列の札にして、名前・重さ・押す場所を広げた。選択中は黄色と✓で示す。狭くなる船の下の案内は2行に収める。メロディ側へCSSを適用せず、classicの指定に限定した。

PCの最終表示では札が棚いっぱいへ縦に伸びていたため、0.9.26でPCの札を64px以上の内容に合う高さにそろえ、木の棚の上から並べる形へ修正した。スマホの配置、絵、進行、操作は変更していない。

案内欄の固定高さを保持し、操作ボタンの文字が変わっても操作段の高さが変わらないよう固定した。レバーの条件文は下端の船情報と重なっていたため、上の独立した紙札へ移した。物理的なレバーの高さや止まる位置は変更していない。

[実画面と素材の保存先](../visual-samples/2026-11-22-classic-finish/README.md)。

## 併せて補修した更新ボタン

基準版のapp.jsは、削除された旧画面の状態変数Gを更新可否の判定に残していた。実際のapp.jsと更新管理を使い、準備済みの更新通知だけを制御した検査で「G is not defined」となり、更新を適用できないことを再現した。

この参照を、現在の画面で出航・航海のボタンが無効な間は保留する判定へ置き換えた。表紙と終了後は適用し、航海中と液体準備中は保留する。更新管理・保存処理・進行処理そのものは変更していない。タイトル・航海中・初期の入れ替え準備の3ケースで、参照エラーなしと保留・適用を確認した。

旧0.9.24の画面が動いている間は旧コードのままなので、この修正を受け取る前の更新ボタンは直らない。公開後は、旧画面の更新ボタンと、旧画面をすべて閉じてから新しい版を起動する経路、記録の保持を実際に点検する。
