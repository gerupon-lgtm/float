# PC版の画面配置（0.8.16）

2026-11-06。発案者の依頼により、要件定義書0章のA区分として配置を変更しました。

## 配置

幅1024px以上だけにPC用の配置を適用します。色・書体・木枠・絵は従来のままです。

- 航路：左に大きい盤面、右に比重・重さ・深さ、式、説明、荷物、出航操作。右欄が長い場合は右欄の中を縦にスクロールできます。
- 紙芝居、天秤、3択、連続プレイの結果：左に絵、右に文と操作。絵の縦横比は維持します。
- 表紙：PRISM・AQUAのPC版と同じ左のロゴ／象徴・右のメニュー。内容幅1000px、左右比1.15:1、列間24pxを参考にしています。
- メニュー：選択プレイと連続プレイは3列、おはなしの読み返しは2列。内容の幅を1040pxに収めています。

アプリ全体は1600px上限、操作欄は340〜420pxです。盤面と紙芝居の大きさはCSSで調整し、SVGの内部座標は変更していません。

幅1024px未満では、追加した包み要素を `display:contents`（配置上の箱を作らない指定）にして、従来の縦並び・余白・末尾ボタンの表示を維持します。

## 変更ファイル

- `src/ui/app.js`：画面の包み要素と配置用クラス、表紙の左右グループ、表示版0.8.16。
- `src/ui/style.css`：幅1024px以上の配置、操作欄の縦スクロール、スマホの末尾ボタン表示の保持。
- `package.json`：0.8.16。ビルドが配信用フォルダーを版ごとに作るため、読み込み先も `v0.8.16/` に変わります。

`src/logic`、`src/content`、`src/sound`、`src/ui/audio.js`、`src/ui/art.js`、盤面の描画・船の深さの計算・出航処理は変更していません。
