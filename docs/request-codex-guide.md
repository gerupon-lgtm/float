## 3. 守ってほしいこと

- **文の中身と数字は変えないこと：** 次のものは Claude の担当です。直したいときは、発案者に伝えてください。
  - 計算式
  - 比重

- **数字は画面側で入れること：** 比重と1マスの重さは、`src/logic` の値から入れています。絵や文に数字を焼き込まないでください（C-01）。

- **配置と言い回し：** 発案者の指示で、すぐに変えてかまいません（0章のA）。
