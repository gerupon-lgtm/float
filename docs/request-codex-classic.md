# Codex への依頼（4回目）：元の遊び方の新しい画面の絵

2026-11-22 Claude 作成。発案者の依頼で作りました。発案者がこの依頼書を使って Codex に依頼します。

## 1. いまの状態

発案者の希望で、元の遊び方（水・油・水銀の15面）の画面を、航路のメロディと同じ形に組み替えました。画面の組み立てと進行は Claude が作りました（`src/ui/classic.js`）。

| 場所 | いまの中身 |
|---|---|
| 上 | 航路図。横は航路の順番（出航 → 関門 → 港）、縦は深さ（上ほど浅く、音は高い）。浅瀬は砂、橋は木、レバーは赤い点線で、液体ごとに背景の色を変えている |
| 中 | 手がかりの3つの枠（液体の比重・船全体の重さ・沈む深さ） |
| 中 | 船の拡大と、右に荷の棚。積み方の面は、荷を選んで船の上を押して積む（メロディと同じ）。それ以外の面は、棚の荷を押すと積む／下ろす |
| 下 | 案内、ボタン（深さの音・ひとつ戻す／全部下ろす・出航） |

出航すると棚が隠れ、関門が右から左へ流れてきます。船はその上や下を通り抜け、当たったときは船の前で止まります。最後は岸壁に着き、航路図にエウレカの判が押されます。

これまで使っていた航路全体の絵（船が左から右へ進む断面図）は使わなくなりました。

## 2. お願いしたいもの

### 優先度1：Claude が仮に描いた部分の絵

| 名前 | いまの描き方 | 守ること |
|---|---|---|
| 船台（台に載った船） | 砂の斜面と、2本の木の台。水4・5、油4・5で、出航前の船を載せる | 出航で船が液体へ下りる。船の絵の位置は `bottomY()` の計算に従う |
| 拡大した場面の水中レバー | 既存の `lever-arm` の絵と柱。赤い点線がレバーの高さ | レバーの高さは判定と同じ基準（`WATER + 深さ×U`）。船底がそこまで届けば押せる |
| 入れ替え室（拡大した場面） | 看板に「入れ替え室」と出して、液体の色を替えるだけ | 液体を替えると深さが変わる。替わる時間は Claude の担当 |
| 航路図のレバーと入れ替え室 | レバーは赤い点線と柱、入れ替え室は列の左右で背景の色を変えている | 位置と高さは航路図の目盛りに従う |

### 優先度2：横置きと PC

メロディと同じ CSS（`.melody-layout`）を使っています。荷が多い面（水銀1・2は8個）は、棚の札を小さくして並べています（`.mshelf.many`）。見やすくなるように整えてください。

## 3. 守ってほしいこと

- **計算・判定・進行は変えないこと（C-01、C-03）：** 判定の順番、船が動く順番と時間、関門で止まる位置は Claude の担当です。
- **見た目の高さを判定に合わせること：** 船べりは船の高さ5（`CL_BOAT_TOP`）、浅瀬の面・橋の下面・レバーの高さは判定と同じ基準で描いています。絵と判定がずれると、当たっていないのに当たって見えます。
- **音なしでも分かること、スマホ縦の1画面に収めること：** メロディと同じです。
- **配置と言い回し：** 発案者の指示があれば、すぐに変えてかまいません（0章のA）。
